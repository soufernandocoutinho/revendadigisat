# Página de apresentação dos sistemas Digisat

Esta é a página comercial de apresentação dos sistemas da **Digisat Tecnologia**, desenvolvida pela **FC Soluções Digitais / Guia Panorama**, representante de vendas autorizado.

A página apresenta o portfólio e permite que potenciais clientes conheçam as soluções disponíveis e entrem em contato com a equipe comercial pelo WhatsApp.

## Sobre o projeto

O catálogo reúne sistemas da Digisat para diferentes necessidades de gestão empresarial, incluindo:

- Digisat MEI;
- Digisat Comercial;
- Digisat Gerencial;
- Digisat Administrador Comercial;
- Digisat Administrador Industrial;
- Digisat Web;
- Digisat Conecta;
- Digisat Pedir Menu.

Entre os recursos apresentados estão o controle de caixa e estoque, emissão de notas fiscais, gestão financeira, administração de filiais, processos industriais, gestão em nuvem, criação de lojas virtuais e atendimento por cardápio digital.

Esta página não é o site oficial da Digisat Tecnologia. Ela funciona como uma página institucional e comercial da FC Soluções Digitais / Guia Panorama, responsável pela apresentação dos sistemas, orientação comercial e contato com o cliente.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Bootstrap 5.3.3;
- Dados estruturados JSON-LD;
- Google Tag Manager, Google Analytics e Google Ads;
- Meta Pixel;
- Cloudflare Web Analytics.

As integrações de rastreamento são ativadas somente após o consentimento do visitante. O projeto também conta com recursos de acessibilidade, navegação responsiva e configuração de privacidade.

## Estrutura

- `index.html`: estrutura, conteúdo, metadados e dados estruturados da página;
- `assets/css/style.css`: estilos principais e responsividade;
- `assets/css/consent.css`: estilos do aviso de privacidade;
- `assets/js/main.js`: navegação, menu móvel e eventos da página;
- `assets/js/consent.js`: consentimento de privacidade e integrações opcionais;
- `assets/img/`: logotipos e imagens utilizadas no catálogo.

## Execução local

Por ser uma página estática, basta abrir o arquivo `index.html` em um navegador ou executar um servidor local, por exemplo:

```bash
python3 -m http.server 8000
```

Em seguida, acesse `http://localhost:8000`.
